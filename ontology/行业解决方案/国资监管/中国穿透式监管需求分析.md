# 中国穿透式监管需求分析

## 二、中国现在真正需要“穿透”什么？

从这些招标项目和监管政策来看，可以把需求概括成一句话：

> **从集团的一张报表，穿透到下面某一家子公司、某一个项目、某一份合同、某一笔资金、某一个交易对手、某一次决策，最后能够找到具体责任人。**

这比传统 BI 或者国资监管大屏深很多。

### 1. 组织和股权穿透

首先要解决的是“**到底管了多少企业**”。

例如：

集团  
→ 二级公司  
→ 三级公司  
→ 四级公司  
→ 项目公司  
→ 参股公司  
→ 境外公司。

监管系统需要知道每家企业的股权比例、实际控制关系、管理关系、法人、董监高、最终控制主体，以及企业之间的关联关系。

金融监管领域更进一步，需要穿透到**股东、实际控制人、一致行动人、最终受益人**。国家金融监管总局也明确把人工智能、大数据等技术用于丰富穿透式监管工具。

参考：
- 国家金融监督管理总局：https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=1239741&itemId=928

---

### 2. 资金穿透

这是目前最明确、最容易形成采购项目的一类。

例如发现：

**集团 → A公司 → B项目公司 → 某供应商 → 某关联公司**

发生一笔 5000 万元支付。

监管人员不能只看到：

> “投资支出：5000万元。”

而是要一路点进去看到：

> 哪个银行账户  
> → 哪一笔付款  
> → 对应什么合同  
> → 对应哪个项目  
> → 谁审批  
> → 为什么付款  
> → 收款公司是谁  
> → 和集团高管有没有关联关系。

宁夏直接把项目名称定义为**“司库穿透式监管平台”**，实际上就是这一类需求。

参考：
- 宁夏政府采购网：https://www.ccgp-ningxia.gov.cn/public/NXGPPNEW/dynamic/contents/CGGG/ZHBGG/content.jsp?cid=317&id=8b80b27b9a8081af019a9ad455c47bb4&sid=1&type=ZB

政府投资领域也已经出现同样模式。广州明确要求使用“数字财政”和政府投资项目资金穿透式监管系统，对**中标人、分包单位、材料供应商、劳务分包单位**的资金流向进行监管并异常预警。

参考：
- 广州市发展和改革委员会：https://fgw.gz.gov.cn/gkmlpt/content/10/10400/post_10400984.html

---

### 3. 采购和招投标穿透

这是未来很大的场景。

监管不是只看：

> 某公司今年采购100亿元。

而是要穿透到：

采购需求  
→ 采购计划  
→ 招标文件  
→ 投标企业  
→ 股东关系  
→ 评标专家  
→ 中标结果  
→ 合同  
→ 验收  
→ 付款。

然后识别：

- 围标
- 串标
- 陪标
- 关联企业投标
- 异常报价
- 拆分采购
- 应招未招
- 先实施后招标
- 异常评委打分
- 供应商利益关联

广州已经提出建立机器码、文件创建标识码、工程量清单软件锁号、投标文件异常一致、报价规律性差异、专家异常评分等自动比对预警能力。

参考：
- 广州市发展和改革委员会：https://fgw.gz.gov.cn/gkmlpt/content/10/10400/post_10400984.html

所以未来**采购穿透监管**很可能成为一个独立的大产品。

---

### 4. 合同穿透

典型链路是：

**年度预算 → 项目 → 采购 → 合同 → 发票 → 验收 → 付款。**

系统需要发现：

- 合同金额异常
- 补充协议异常
- 无合同付款
- 超合同付款
- 合同倒签
- 关联交易
- 长期未履约
- 付款条件未满足却支付

关键不是做一个“合同管理系统”，而是把合同和：

**项目、采购、供应商、资金、发票、人员、审批**

全部连接起来。

这就是所谓的“穿透”。

---

### 5. 投资穿透

投资监管未来也是重点场景：

投资计划  
→ 项目立项  
→ 可研  
→ 尽调  
→ 三重一大  
→ 投资决策  
→ 合同  
→ 出资  
→ 项目运营  
→ 投后管理  
→ 退出。

系统需要判断：

- 是否属于主业
- 是否违规非主业投资
- 是否超授权投资
- 是否控股不控权
- 投资是否超概算
- 收益是否低于预期
- 是否形成重大损失

市场上的相关方案已经把“投资申请 → 决策 → 合同 → 资金支付 → 投后运营 → 后评价 → 退出”作为完整穿透链条。

参考：
- 用友：https://www.yonyou.com/subject/yonbip/news/5305

---

### 6. “三重一大”穿透

这可能是**国资监管非常核心的数据源**。

所谓：

- 重大决策
- 重要干部任免
- 重大项目安排
- 大额资金运作

传统系统记录：

> 某事项已经通过董事会。

穿透监管则需要知道：

谁提出  
→ 谁参加会议  
→ 谁表决  
→ 决策依据是什么  
→ 是否违反权限  
→ 后续有没有执行  
→ 最终产生了什么资金和经营结果。

贵州水投项目已经明确建设制度管理、事项管理、会议管理、决策执行以及向国资委数据报送等能力。

参考：
- 致远互联：https://www.seeyon.com/News/desc/id/7431/typeid/3.html

## 三、真正的技术核心其实不是“大屏”，而是这 6 层

如果把现在中国的穿透式监管需求做成一个产品架构，可以设计成：

### 第一层：监管对象库

包括：

- 企业
- 组织
- 人员
- 股东
- 实际控制人
- 项目
- 供应商
- 客户
- 银行账户
- 其他监管对象

### 第二层：监管数据底座

主要数据来源包括：

- ERP
- 财务
- 司库
- 采购
- 合同
- 投资
- 资产
- 项目
- OA
- 三重一大
- 银行流水
- 工商数据
- 司法数据
- 信用数据

湖北项目单独采购工商、司法、信用数据，就是这个趋势非常明确的证据。

参考：
- 湖北相关采购信息：https://hbs.qianlima.com/zbcontent-614623734.html

### 第三层：关系图谱

这是穿透监管平台最重要的一层之一：

> 企业—股东—人员—供应商—合同—项目—账户—交易

全部形成关系网络。

否则实际上只能做报表，做不了真正的“穿透”。

### 第四层：风险指标和规则模型

例如：

> 供应商股东 = 本企业员工亲属  
>
> 同一 IP 上传不同投标文件  
>
> 3 家公司报价规律高度相似  
>
> 合同金额 1000 万但累计付款 1200 万  
>
> 子公司资金流向非主业投资  
>
> 短期内连续拆分采购  
>
> 供应商刚成立就取得大额合同。

把这些变成：

**规则 + 指标 + 模型**

### 第五层：AI监管

这也是 2026 年出现明显增长的一层：

- 自然语言查监管数据
- 合同 AI 审查
- 招标文件 AI 审查
- 风险自动分析
- 异常交易识别
- 企业关系分析
- 风险原因解释
- 自动形成核查报告

国务院国资委当前强调的是“智能化穿透式监管体系”，金融监管总局也明确提出加大人工智能、大数据技术应用、丰富穿透式监管工具。

参考：
- 国务院国资委：https://www.sasac.gov.cn/n2588025/n2643314/c35542876/content.html

### 第六层：风险闭环

这层非常关键：

> 发现风险  
> → 自动预警  
> → 生成问题线索  
> → 派发核查任务  
> → 企业解释  
> → 上传证据  
> → 整改  
> → 复核  
> → 销号  
> → 责任追溯。

湖北的采购项目已经直接提出“动态预警监控 + 预警处置闭环”，说明市场已经开始从“看风险”转向“处理风险”。

---

## 四、目前最大的市场机会在哪里

结合这些标讯，可以把中国穿透式监管市场分成四块：

| 市场 | 当前需求强度 | 核心采购内容 |
|---|---:|---|
| **国资委 / 央国企 / 地方国企** | ★★★★★ | 全级次监管、司库、三重一大、投资、采购、合同、风险 |
| **政府投资 / 财政资金** | ★★★★★ | 专项资金、工程资金、财政资金流向穿透 |
| **金融监管 / 金控集团** | ★★★★☆ | 股权、实控人、最终受益人、关联交易、风险传导 |
| **公共资源 / 招投标监管** | ★★★★☆ | 围串标、资金、供应商关系、AI评审、异常行为 |

尤其值得注意的是，**“国资穿透监管”未来很可能不是一个单独系统，而是一套跨业务的监管平台**。

也就是说最终会覆盖：

**企业 + 人 + 股权 + 财务 + 资金 + 采购 + 合同 + 投资 + 项目 + 资产 + 供应商 + 风险 + 三重一大 + 外部数据。**

这也是为什么未来真正有竞争力的穿透式监管产品，核心不是传统 ERP，也不是传统 BI，而更接近：

> **数据平台 + Ontology / 知识图谱 + 规则引擎 + 风险模型 + 工作流 + AI Agent + BI**

这样的组合。

如果要做产品，可以优先做一个 **“国资国企穿透式监管平台”**，第一版集中在以下 8 个领域：

1. 组织股权
2. 司库资金
3. 采购
4. 合同
5. 投资
6. 三重一大
7. 风险预警
8. 外部企业数据

而不是一开始把所有国资业务全部做完。
