的最小垂直链路,可用少量 seed 数据演示。

- plan/object-type-functional-spec.md —— 尤其 §1.2(平台范围:只做管理面、
  不做 runtime 数据)、§4(元数据模型数据字典,Object Type / Property 字段表、
  base type 全集、Key 语义)、F-OT-01 / F-OT-02、§6(命名校验与不可变约束)。
- plan/object-type-build-order.md —— 只看 W0 底座的定义与验收锚点表
  (W0 子项 → 服务 F-OT → 验收锚点),确认本片要覆盖哪些底座子项。

【范围】
- 只做读路径:对象类型能被持久化并被读出(列表 + 详情),不实现创建 /
  编辑 / 保存通道 / 状态流转 / 删除 / 权限强制——那些是后续波,不要顺手做。
- 属性作为对象类型的组成部分只读展示;字段语义严格按 §4 数据字典;
  命名 / 唯一性 / 不可变(id、rid、apiName、主键归属等)按 §6 落为持久化层约束。
- 平台范围遵循 §1.2:无 runtime 数据,不做对象实例、索引、数据集。

【验收要点(以 F-OT-01/02 为准)】
- 列表能从真实存储读出;可按状态过滤;关键字命中 display name 与 api name。
- 详情能展示完整定义:概览(元数据 + 主键/标题键归属,不可变字段只读);
  属性(含 base type / required / visibility),可读展示。
- pnpm gen:contract 生成正常;verify 全绿。

【开工前请在澄清阶段先确认(影响模型形状;未定则以括号内为默认,且明示需求方)】
- Q3 权限模型:三角色 Viewer / Editor / Owner(默认)还是 project-based;
- Q5 是否多 ontology / space:单 ontology、唯一性全局(默认)。
